Birds · master redesign plan

One plan: structure, charts, and the Aviary — integrated.

The full redesign in a single map. Structure sets the navigation and pages, charts set how every number is read, and the Aviary becomes the ambient lens on the live feed. Two ideas run through all three: presence over chatter, and one question per surface.

Hand to Claude Code with MASTER_SPEC.md (the integrated build doc), CHARTS_SPEC.md (chart detail), and design_handoff_aviary/ (the reusable Aviary engine). This page is the visual map of how they fit together.
Nav Home · Birds · Forecast · Atlas Charts 6 surfaces, presence-first Aviary lens on the live card
Strand 1

Structure

Responsive shell, a persistent Location · Device · Time scope, and pages each built to answer one thing — Home as settled truth, Birds as the review surface, Recent as presence.

Strand 2

Charts & data-viz

Every chart re-encoded: presence over raw chatter, labeled axes for every line, the day/night backdrop kept but labeled, Lucide icons, plain copy.

Strand 3

Aviary

The ambient "who's in the yard now" scene, placed where it belongs — as the live card's expanded, cast-ready view, on the same rolling-15-min data.

03 — The Aviary

An ambient lens on the live feed

The Aviary shows who's in the yard right now — each species heard in the rolling last 15 minutes flies in, pecks and hops while it keeps calling, lifts off when it goes quiet. It reads the same live data as the histogram, so it lives with the live card — surfaced as its expanded, cast-ready view, not as a fifth nav item.

How it behaves

01
Same data as the live cardDriven by the rolling-15-min present-species set from the live source — no new data, just a second representation.
02
Scope-coupledRequires a live (always-on) device in scope, like the histogram. Default Yard · Yard Mic makes it always available; changing Location/Device repoints it.
03
Quiet-yard empty stateHeard nothing in 15 min? A calm empty yard with a "listening…" note — a better idle than a flat-lined histogram.
04
Mobile = fullscreen takeoverOpens from the live card, not a bottom tab. Side panel ("in the yard now" + controls) drops under the scene below 820px.
🛠
The engine is already built — reuse it. aviary-voxel.js (renderer + species) and aviary.js (scene + window.Aviary API) are production-ready. Port only the chrome; feed live data with Aviary.setPresent([...]). Don't rebuild the renderer or bird models.
✎
Naming. "Aviary" / "Live Aviary" reads well as "your birds, live" and needs no nav label of its own. If a more literal name is ever wanted, "The Yard" maps directly to the scene.
