# meta_reject.txt — SINGLE SOURCE OF TRUTH for the vacuous/meta-task reject list.
#
# A "meta task" is vacuous list-management spam: reviewing, prioritizing,
# reducing, or otherwise managing the TODO list is the overseer's JOB, not a
# deliverable. These slip past exact/near dedupe because each is worded
# slightly differently, so we match on distinctive lowercased SUBSTRINGS.
#
# Consumed by (all three MUST reject the same list):
#   - backend/services/letta_tools/workshop.py  wkshp_propose_task  (reads this
#     file at runtime; the Letta sandbox can't import shared/)
#   - scripts/work_generator.sh                 append_item  (via --check CLI)
#   - scripts/graduate_proposals.sh             (imports is_meta_reject)
#
# Matching: task text is lowercased + whitespace-collapsed, then each marker
# below is tested as a substring. One line per marker. `#` lines are comments.
# A concrete task names a concrete referent (file/service/endpoint/feature) and
# won't match; pure list-management prose will.

verify / finish caveat
finish caveat on prior
