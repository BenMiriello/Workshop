As of 2026-08-10 the design system is no longer `frontend/src/ui`. It lives at `packages/ui`, is version **0.2.0**, and is consumed by package name only.

**Why it moved:** the old setup had a `package.json` with no build and an `exports` map pointing at `../styles/*` (above the package root, which `npm pack` drops). Every consumer resolved it through a bundler alias onto the source directory, so the version number did nothing. `Menu` changed from an `items` prop to `MenuItem` children during 1.x with no bump; in-repo call sites were fixed in the same commit so nothing failed here, and out-of-repo consumers broke silently against a `^1` pin.

**Cross-distro implication (not recorded anywhere in this repo):** another Workshop distro consumes this kit as a path alias into `frontend/src/ui`. That path no longer exists. Those consumers need to move to `@workshop/ui` 0.2.0 and follow the migration notes in `packages/ui/CHANGELOG.md` — in particular `Markdown` moved to `@workshop/ui/markdown`, `Map` to `@workshop/ui/map`, and `components.css` is exported as `@workshop/ui/styles.css`.

**Enforcement now in place:** `packages/ui/api/ui.api.md` snapshots the public surface and `scripts/check_design.sh` fails when it moves without an update; `reviewer.sh` typechecks and design-lints `packages/ui` alongside `frontend`.

**Resolution (updated 2026-08-11):** there is NO bundler alias. `node_modules/@workshop/ui` is a workspace link to `packages/ui`, and the package's `exports` map decides which subpaths resolve — `@workshop/ui/controls` does not. Vite selects sources over `dist/` via `resolve.conditions: ["workshop-source"]`; keep that list narrow, adding `"browser"` made recharts resolve a DOM-only build that throws under vitest. Mobile may import ONLY `@workshop/ui/tokens.js` (metro.config.js throws on anything else, since the primitives are react-dom).

**Local caveat:** `npm install` at the root FAILS offline (`ENOTCACHED` — npm needs registry metadata even with a warm cache), and egress is blocked here. The two links it would create were made by hand: `node_modules/@workshop/ui -> packages/ui` and `packages/ui/node_modules -> frontend/node_modules`. Both are gitignored, so a fresh clone needs a real `npm install` at the root; `check_design.sh` fails with that exact instruction if the link is missing.
